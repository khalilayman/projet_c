# **Snake C Edition**

Un jeu Snake en C avec des graphismes variés, plusieurs terrains, des modes de difficulté et un système de score.

## **Le jeu**

Un Snake classique mais revisité : choisissez votre terrain, votre difficulté, et essayez de battre votre meilleur score.

## **Fonctionnalités**

- **Plusieurs terrains** — Chaque terrain a son propre style graphique
- **Modes de difficulté** — De facile à difficile
- **Score** — Compteur de points et meilleur score sauvegardé
- **Graphismes différents** — Rendu visuel propre à chaque mode
